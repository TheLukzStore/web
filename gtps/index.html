📖 Panduan Bermain

Ikuti langkah berikut untuk menggunakan BERKAHPS.

🚀 GTPS Cloud Login

1
Buka aplikasi BERKAHPS Buka aplikasi APK BERKAHPS yang sudah kamu install di perangkat.
2
Masuk ke menu GTPS Cloud Login Pada halaman utama aplikasi, cari dan buka menu:
GTPS Cloud Login
3
Masukkan nama server Pada kolom nama server, masukkan nama server berikut:
BERKAHPS
4
Tekan Create Account Setelah nama server BERKAHPS dimasukkan, tekan tombol:
Create Account
5
Selesai! Setelah menekan Create Account, proses konfigurasi selesai.

Sekarang kamu sudah siap untuk bermain di server BERKAHPS.
✅ Berhasil!
Jika kamu sudah memasukkan nama server BERKAHPS dan menekan Create Account, berarti konfigurasi sudah selesai.
